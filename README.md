# links for me ✳

Um diretório leve, responsivo e em português para encontrar recursos de estudo, criação e jogos. Feito em HTML, CSS e JavaScript puro — sem dependências, rastreadores ou conteúdo de terceiros hospedado no repositório.

## Rodar localmente

Abra `index.html` no navegador. Para publicar como site estático, ative o **GitHub Pages** nas configurações do repositório e selecione a branch/pasta que contém esse arquivo.

## Sobre os links e as regras

Este repositório apresenta links externos para serviços de terceiros; não incorpora, distribui nem hospeda os sites apontados. O projeto foi organizado para ser um diretório informativo e respeitar os termos aplicáveis do GitHub: não oferece ferramentas para contornar filtros, firewalls, controles de acesso ou regras escolares. Links de mirrors/proxies de procedência incerta, conteúdo adulto e destinos potencialmente não autorizados foram omitidos. A lista é uma seleção comunitária, não uma recomendação ou garantia sobre serviços externos; cada pessoa deve respeitar as regras da escola, a legislação aplicável e os termos dos respectivos serviços.

## Contribuições

Sugira recursos educacionais e serviços legítimos, com descrição clara e link oficial. Não envie links para contornar controles de acesso, conteúdo adulto, material sem autorização ou destinos enganosos. Links externos podem mudar e devem ser verificados antes de serem adicionados.
